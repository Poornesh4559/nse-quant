System Architecture

A fully self-hosted NSE quant pipeline: collect market data, store it in TimescaleDB, score news sentiment, run analysis + ML signals, paper-trade with an LLM gate, and surface everything on this dashboard.

Decision Logic

composite = 0.40·momentum + 0.35·ML + 0.25·sentiment
1 Guardrailrisk / exposure checks
2 Regime gaterisk-on required
3 LLM gaterating ≥ 0.60
4 Executepaper order
